📅 Wanneer

Kies de datum en tijd waarop je wil spelen.

👥 Spelers

Selecteer 3 medespelers via de zoekboxen. Jij (Joris) bent altijd speler 1.

🎾 Baan reserveren

Tik op de groene knop onderin. Afhankelijk van de speeldatum:

  • Dag 0 t/m dag+2 — boekt direct (mail van ETV binnen 5 min)
  • Dag+3 of verder — wordt ingepland; automatisch gereserveerd op de reserveringsdatum om 07:01

📋 Mijn reserveringen

Toont je actieve reserveringen. Wordt dagelijks om 07:30 bijgewerkt. Tik 🔄 voor een directe refresh (~1.5 min). Tik 🗑️ om een reservering te annuleren.

🕒 Ingeplande reserveringen

Reserveringen die nog te ver in de toekomst liggen. Worden automatisch verwerkt op de reserveringsdatum om 07:01. Tik 🗑️ om een geplande reservering te verwijderen.

⚙️ GitHub Token

Vereist voor alle acties. Maak een classic PAT aan op github.com/settings/tokens met scope workflow. Eenmalig instellen via het tandwiel-icoon.

🔴 Rode badge op ⚙️

Je GitHub Token verloopt binnenkort of is verlopen. Genereer een nieuwe en sla op via het tandwiel-icoon.
